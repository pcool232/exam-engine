Accepted formats

JSON — the only format that can carry pictures and exam settings 
{
  "exam": {
    "title": "Design and Technology Paper 1",
    "code": "17/1",
    "subject": "Design and Technology",
    "year": "October/November 2018",
    "durationMinutes": 60,
    "passMark": 50,
    "shuffleQuestions": false,
    "shuffleOptions": false,
    "showAnswers": true
  },
  "questions": [
    {
      "question": "What is 2 + 2?",
      "options": ["3", "4", "5"],
      "correct": "B",
      "explanation": "Basic addition",
      "marks": 1,
      "image": "data:image/jpeg;base64,..."
    }
  ]
}

The exam block is optional and is used only when you import a whole file as a new paper; you can change every value on the next screen. Options may also be objects: {"text": "4", "correct": true}. correct takes a letter, a zero-based index, the full option text, or an array of those. image takes a data: URI, a /static/… path or an https:// URL.

Past-paper text (pasted or in a .txt, .docx or .pdf file) 
1. What is the capital city of Kenya?
A. Mombasa
B. Nairobi
C. Kisumu
D. Eldoret
Answer: B
Explanation: Nairobi has been the capital since 1907.

Question 2
Which TWO of these are prime numbers? (Choose two)
A) 9
B) 11
C) 15
D) 17
Correct Answers: B, D

Also understood: Ans:, Key:, Correct Answer:, options written as (A) or A), and a leading * to mark the right option instead of an answer line. "Choose two" makes a question multiple-answer automatically. Options must be lettered A–J.

CSV spreadsheet 
question,option_a,option_b,option_c,option_d,correct,explanation
What is 7 x 8?,54,56,48,64,B,Seven eights are fifty-six
Which are mammals?,Whale,Shark,Bat,Trout,"A,C",Mammals nurse their young

A header row is required. Recognised columns: question, option_a…option_j, correct (also answer or key), explanation, type, marks and image. The answer cell takes B, A,C, AC, or the full text of an option.

Word and PDF

The text is pulled out of the document and then read exactly like pasted past-paper text, so the same layout rules apply, and pictures in the document are not carried across. A PDF made by scanning paper holds images rather than text, so nothing can be extracted from it — for those, type or paste the questions instead.
